# Prism RPC — Discord Rich Presence для Prism Launcher

Фоновое приложение на Rust, которое отображает активность Prism Launcher в Discord
и сворачивается в системный трей Windows.

## Что отображается в Discord

| Ситуация | Details (верхняя строка) | State (нижняя строка) |
|---|---|---|
| Лаунчер открыт, игра не запущена | `Сидит в лаунчере` | `Ник: Имя` |
| Создание / загрузка сборки | `Создаёт сборку: Название (1.20.1)` | `Ник: Имя` |
| Открыто меню создания сборки | `Создаёт новую сборку...` | `Ник: Имя` |
| Сборка только что создана | `Создал сборку: Название (1.20.1)` | `Ник: Имя` |
| Игра запущена (одиночная / мир) | `Сборка: Название (1.20.1)` | `Ник: Имя` |
| Игрок на сервере | `Сервер: reallyworld.ru` | `Ник: Имя` |

## Быстрый старт

### 1. Установить Rust

Если Rust не установлен:
```
https://rustup.rs/
```
После установки откройте **новый** терминал.

### 2. Создать Discord Application

1. Зайдите на https://discord.com/developers/applications
2. Нажмите **New Application**, дайте имя `Prism Launcher` (или любое другое)
3. Скопируйте **Application ID** (он же Client ID)
4. В разделе **Rich Presence → Art Assets** загрузите изображение с ключом `prism_logo`
5. Откройте `src/discord.rs` и замените:
   ```rust
   pub const DISCORD_CLIENT_ID: &str = "YOUR_DISCORD_APP_ID_HERE";
   ```
   на ваш ID, например:
   ```rust
   pub const DISCORD_CLIENT_ID: &str = "1234567890123456789";
   ```

### 3. Собрать и запустить

**Debug-сборка** (с консольным окном, полезно при отладке):
```powershell
cargo build
.\target\debug\prism-rpc.exe
```

**Release-сборка** (без консоли, запускается в трей):
```powershell
cargo build --release
.\target\release\prism-rpc.exe
```

### 4. Автозапуск

Автозапуск настраивается прямо из системного трея:
- При первом запуске автозапуск регистрируется в реестре Windows (`HKCU\...\Run`) автоматически.
- В контекстном меню трея есть пункт **🚀 Автозапуск с Windows**, где его можно в любой момент включить или выключить в один клик.

## Системный трей

После запуска иконка появится в системном трее (область уведомлений рядом с часами).

| Действие | Результат |
|---|---|
| Левый клик по иконке | Показывает текущий статус |
| Правый клик → **📊 Текущий статус** | То же самое диалоговое окно |
| Правый клик → **🚀 Автозапуск с Windows** | Переключает автозапуск вместе с Windows |
| Правый клик → **❌ Выход** | Завершает приложение |

## Как работает обнаружение

### Никнейм игрока
Считывается из `%APPDATA%\PrismLauncher\accounts.json` (активный аккаунт).

### Активная сборка
Приложение сканирует папку `%APPDATA%\PrismLauncher\instances\` и ищет
директорию, в которой файл `minecraft/logs/latest.log` был изменён **не более 2 минут назад**.
Название и версия берутся из `instance.cfg`.

### Текущий сервер
Парсится хвост файла `latest.log` активной сборки.
Ищется последняя строка вида:
```
[Client thread/INFO]: Connecting to reallyworld.ru., 25565
```

| Крейт | Назначение |
|---|---|
| `discord-rich-presence` | Discord IPC / Rich Presence |
| `tray-icon` | Системный трей и контекстное меню |
| `winit` | Цикл событий для трея |
| `serde` / `serde_json` | Парсинг JSON (accounts.json) |

## Отладка

Запустите debug-сборку — консоль покажет все логи:
```powershell
$env:RUST_LOG="info"; .\target\debug\prism-rpc.exe
```

Для детальных логов:
```powershell
$env:RUST_LOG="debug"; .\target\debug\prism-rpc.exe
```
