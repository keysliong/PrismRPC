PrismRPC 🚀

PrismRPC — это быстрый, легкий и надежный клиент для Discord Rich Presence (DRP), написанный на Rust. Работает в фоновом режиме и управляется через системный трей (system tray).

🌟 Особенности

⚡ Высокая производительность: Написан на Rust, потребляет минимум ресурсов процессора и оперативной памяти.

📌 Работа в трее: Сворачивается в системный трей возле часов, не занимая место на панели задач.

🎨 Гибкая настройка: Полная кастомизация статуса, иконок, текста и кликабельных кнопок через конфигурационный файл.

🔄 Автореконнект: Автоматически восстанавливает соединение с Discord, если клиент был перезапущен.

🛠️ Требования

Установленный Rust / Cargo (только для сборки из исходников).

Запущенный клиент Discord.

🚀 Установка и запуск

Готовый релиз (из раздела Releases)

Скачайте последнюю версию со страницы Releases.

Распакуйте архив в удобную папку.

Отредактируйте config.toml под свои нужды.

Запустите prism_rpc.exe — приложение автоматически запустится и свернется в трей.

Сборка из исходников

# Клонирование репозитория
git clone https://github.com/your-username/PrismRPC.git
cd PrismRPC

# Сборка релизной версии
cargo build --release


Исполняемый файл появится в папке ./target/release/prism_rpc.

⚙️ Настройка (config.toml)

Создайте или отредактируйте файл config.toml, который находится в одной папке с исполняемым файлом приложения:

client_id = "123456789012345678"

[presence]
details = "Фоновый статус"
state = "PrismRPC v0.1.0"
large_image = "rust_logo"
large_text = "Rust App"
small_image = "ferris"
small_text = "Работает в трее"

[presence.timestamps]
show_elapsed = true

[[presence.buttons]]
label = "GitHub"
url = "https://github.com/your-username/PrismRPC"


🖱️ Управление через трей

ЛКМ / ПКМ по иконке: Открывает меню управления.

Перезагрузить конф: Применяет изменения из config.toml без перезапуска приложения.

Выход: Полностью закрывает приложение и убирает статус из Discord.
