# PrismRPC 🚀

**PrismRPC** — это быстрый, легкий и надежный клиент для **Discord Rich Presence (DRP)**, написанный на **Rust**. Работает в фоновом режиме и управляется через системный трей (system tray).

---

## 🌟 Особенности

* ⚡ **Высокая производительность:** Написан на Rust, потребляет минимум ресурсов процессора и оперативной памяти.
* 📌 **Работа в трее:** Сворачивается в системный трей возле часов, не занимая место на панели задач.
* 🎨 **Гибкая настройка:** Полная кастомизация статуса, иконок, текста и кликабельных кнопок через конфигурационный файл.
* 🔄 **Автореконнект:** Автоматически восстанавливает соединение с Discord, если клиент был перезапущен.

---

## 🛠️ Требования

* Установленный [Rust / Cargo](https://www.rust-lang.org/) (версии 1.70.0 или выше — *только для сборки из исходников*).
* Запущенный клиент **Discord**.

---

## 🚀 Установка и быстрый запуск

### Готовый релиз
1. Скачайте последнюю версию архива со страницы [Releases](https://github.com/keysliong/PrismRPC/releases).
2. Распакуйте архив в удобное место (вместе с файлом конфигурации).
3. Запустите `prism_rpc.exe` (приложение сразу свернётся в трей).

### Сборка из исходников
```bash
# Клонирование репозитория
git clone [https://github.com/keysliong/PrismRPC.git](https://github.com/keysliong/PrismRPC.git)
cd PrismRPC

# Сборка релизной версии
cargo build --release
